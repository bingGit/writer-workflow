# 交互式写作工作流 (/write-article)

本工作流通过**交互式对话**挖掘用户的隐性知识（独特性），结合个人写作风格，生成极具"人味"的深度文章。

## 执行步骤

1. **环境准备**：
   - 加载核心资源：
     - 教练指令：`[独特性挖掘提示词.md](file:///Users/bing/project/me/writer/.gemini/个人经历/独特性挖掘提示词.md)`
     - 写作指令：`[tree-to-article.md](file:///Users/bing/project/me/writer/.gemini/prompts/tree-to-article.md)`
     - 个人风格：`[我的写作风格.md](file:///Users/bing/project/me/writer/.gemini/个人经历/我的写作风格.md)`
   - 读取输入文件（逻辑树/详情文件）。

2. **第一阶段：深度挖掘（交互模式）**：
   - **角色切换**：AI 切换为"独特性挖掘教练"角色。
   - **启动对话**：基于输入文件的主题，向用户发起苏格拉底式提问（参考 `独特性挖掘提示词.md` 的 Workflow）。
   - **多轮交互**：
     - 围绕 **独家数据**、**非理性直觉**、**情感连接** 三个维度进行追问。
     - **注意**：此阶段只需进行对话，直到信息收集充分。
   - **生成报告**：对话结束后，整理生成《个人独特性优势报告》。

3. **第二阶段：生成深度文章**：
   - **整合输入**：
     - 素材 A：原始详情文件内容。
     - 素材 B：刚刚生成的《个人独特性优势报告》（包含用户的原话和故事）。
     - 素材 C：`我的写作风格.md`。
   - **执行写作**：调用 `tree-to-article.md` 逻辑。
   - **保存位置**：
     - `article/yyyy-mm/[标题].md`
     - `article/yyyy-mm/[标题]_writing_logic.md`

## 如何触发

在聊天框中输入：
`/write-article [文件路径]`

## 交互示例

1. **输入**：`/write-article parse_result/知觉_details.md`
2. **AI (教练)**：*"你好！我读了关于‘知觉’的内容。我想知道，在你过去的摄影或观察经历中，有没有哪一刻是你觉得‘我看懂了’但别人觉得你‘疯了’的时刻？（挖掘非理性直觉）"*
3. **用户**：*"有一次我在火车站..."*
4. **AI (教练)**：*(继续追问细节...)*
5. **AI (结束)**：*信息收集完毕，正在为你生成文章...*
