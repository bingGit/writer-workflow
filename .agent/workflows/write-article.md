# 交互式写作工作流 (/write-article) [Sub-agent Version]

本工作流已升级为**多代理协作架构**，通过专用的“数字工匠”实现深度访谈与因果写作的解耦。

## 执行步骤

1. **环境准备与委派 (Orchestration)**：
   - 主代理读取输入的逻辑树/详情文件。
   - **自动委派**：任务将被分发至 `interviewer` (深度访谈员) 子代理。

2. **第一阶段：深度挖掘（Sub-agent: interviewer）**：
   - `interviewer` 启动独立的会话，向用户发起多轮苏格拉底式提问。
   - 目标：产出包含【独家数据】、【非理性直觉】、【情感连接】的《个人独特性优势报告》。
   - **系统论逻辑**：利用子代理的纯净上下文，防止由于由于对话轮次过多导致的因果逻辑漂移。

3. **第二阶段：素材审计（Main Agent）**：
   - 主代理解析报告。如果独特性素材不足以支撑原始逻辑树深度，主代理将打回子代理要求继续追问。

4. **第三阶段：因果写作（Sub-agent: stylist）**：
   - **自动委派**：将原始素材、优势报告及 `我的写作风格.md` 发送至 `stylist` (因果风格家) 子代理。
   - `stylist` 执行最终的文本落地，确保文章具备“呼吸感”与“因果张力”。

5. **存档与交付**：
   - 文章保存至 `article/yyyy-mm/` 目录。
   - 同时生成 `_writing_logic.md` 逻辑解析文件。

## 如何触发

在聊天框中输入：
`/write-article [文件路径]`
