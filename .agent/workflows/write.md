# 内容写作工作流 (Content Writing Workflow) - V2

此工作流激活升级后的 `content-writing-skill` 架构，支持在不同账号模式（Profile）之间无缝切换。

## 何时使用
当您需要以下操作时使用 `/write`：
- 在不同定位的平台（小红书、审美号、思考号）之间进行内容创作。
- 确保创作过程自动匹配正确的【人设】和【方法】。

## 工作流步骤

### 1. 🛑 确定分身 (选择模式)
在开始之前，Agent 必须查阅 `content-writing-skill/技能说明.md`。

1. **载入路由**：
   - 确认当前的创作目标（是引流、沉淀还是深度输出？）。
   - 根据路由表确定模式：`小红书`、`审美公众号` 或 `思考公众号`。

### 2. 🧳 加载上下文
根据选定的模式，Agent 自动载入对应的物理文件：
- 载入 `人设/` 目录下的分身定义（受众、禁区）。
- 载入 `方法/` 目录下对应的特化方法论（如 `方法/小红书/`）。
- 载入 `风格/` 目录下对应的排版指南。

### 3. ✍️ 闭环创作 (生产)
遵循选定方法论的步骤进行创作。
- *如果是跨平台分发*：先完成母本（例如思考推文），再由 Agent 自动切换模式进行“切片”处理。

### 4. ✅ 质量收官
- 使用 `人设/` 文件中的“禁区”规则进行一票否决检查。

## 使用示例
- “/write [模式: 审美公众号] 谈谈关于极简主义的误区”
- “/write [模式: 思考公众号] 我今天的乱七八糟的想法...”
- “把刚刚写好的内容【切片】到小红书”
