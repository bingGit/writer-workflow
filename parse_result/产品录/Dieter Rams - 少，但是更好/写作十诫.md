# 写作十诫 (Ten Commandments of Good Writing)

> **灵感来源**：迪特·拉姆斯（Dieter Rams）的"好设计十原则"
> **核心理念**：少，但是更好。（Weniger, aber besser）

---

## 1. 好的写作是**诚实的**
不伪装、不夸大、不回避。你的观点可以尖锐，但不能是"撒谎"的。用事实和逻辑支撑你的判断，而不是用华丽的词藻掩盖思考的空洞。

## 2. 好的写作是**有因果的**
每一个结论都必须有前因，每一个观点都必须有推导。如果读者问"为什么"，你的文章应该在下一段就能回答。拒绝"信息平铺"，拥抱"逻辑串联"。

## 3. 好的写作是**克制的**
不堆砌形容词，不滥用感叹号，不写你自己都不确定的"金句"。好的文字像贴心的仆人，在需要时出现，在不需要时沉默。

## 4. 好的写作是**具体的**
用场景代替概念，用故事代替道理，用细节代替结论。读者不会被"很感人"打动，但会被"她低头看着手机里那张合照，手指悬在删除键上方五秒钟"击中。

## 5. 好的写作是**有温度的**
温度不是煽情，而是"在场感"。让读者感受到你曾经真的经历过、思考过、困惑过。没有经历的写作是苍白的，没有困惑的写作是傲慢的。

## 6. 好的写作是**易读的**
让文字本身说话。句子越短，击中率越高。段落越清晰，读者越容易跟上你的节奏。不要用复杂结构来显示你的聪明，那是对读者时间的不尊重。

## 7. 好的写作是**有边界的**
知道自己写什么，更知道自己不写什么。一篇文章只解决一个核心问题。如果你想说的太多，那就拆成两篇。贪婪的写作往往一无所获。

## 8. 好的写作是**有节奏的**
长句与短句交错，快节奏与慢节奏交替。好的文章有"呼吸感"——让读者有喘息的空间，也有被击中的瞬间。

## 9. 好的写作是**可检验的**
你的核心观点，读者能否用自己的经历去验证？如果不能，它就只是你的独白。好的写作是一面镜子，让读者照见自己。

## 10. 好的写作是**极简的**
在写完初稿后，问自己一个问题："还能删掉什么？"——删掉那些"没有也不影响理解"的句子。最好的文章，是删无可删的文章。

## 附录：写作的"反面清单"

以下是违反十诫的典型表现，自我审计时可逐条检查：

| 诫条 | 反面表现 |
| :--- | :--- |
| 诚实 | 为了流量而夸大、为了正确而说谎 |
| 因果 | 观点与观点之间毫无联系，像"语录体" |
| 克制 | 每段都想写成金句，结果全是废话 |
| 具体 | 通篇都是"很好"、"很感动"、"意义重大" |
| 温度 | 像机器人一样冷冰冰，或像演员一样假 |
| 易读 | 一句话 80 个字，三个从句嵌套 |
| 边界 | 跑题、发散、一篇文章想解决十个问题 |
| 节奏 | 全是短句像机关枪，或全是长句像催眠曲 |
| 可检验 | 观点玄乎，读者无法用自己的经验去对照 |
| 极简 | 初稿即终稿，从不修改删减 |
