# 水鱼故事构图·品牌发布框架

> 统一的视觉框架,让每次发布都有品牌识别度

---

## 品牌核心元素(固定不变)

### 1. 品牌标识
```
右上角: ~~~~~ 🐟 水鱼故事构图
右下角: ~~~~~ (淡淡的水波纹水印)
```

### 2. 品牌色调
- 主色调: 柔和的蓝灰色 `#E8EEF2`
- 辅助色: 暖米色 `#F5F1E8`
- 文字色: 深蓝灰 `#3A4A5A`

### 3. 品牌标语(选一个使用)
- 不打卡拍照,只思考表达
- 构图诠释故事,让瞬间有意义
- 摄影不是记录,而是表达

### 4. 排版规范
- 留白: 四周至少25%
- 字体: 思源宋体(标题) + 思源黑体(正文)
- 对齐: 左对齐为主
- 尺寸比例：9:16

### 5. 人物一致性
- 保持人物一致性

### 6. 格式
- 使用中文标点符号
- 禁止使用markdown格式，比如加粗 **、横线 ---、列表 - 
- 句与句之间用换行代替

---

## 发布框架模板

### 模板1:故事对比型

**适用场景**: 对比教学、案例分析、"记录vs表达"系列

**固定框架**:
```
┌──────────────────────────────────────┐
│  ~~~~~ 🐟 水鱼故事构图              │ ← 右上角品牌标识
│                                      │
│  ❌ 记录:看到了什么    ✅ 表达:看见了什么 │
│  ┌─────────┐          ┌─────────┐   │
│  │         │          │         │   │
│  │ [内容A] │    VS    │ [内容B] │   │ ← 这里填充你的内容
│  │         │          │         │   │
│  └─────────┘          └─────────┘   │
│                                      │
│  [引导思考的问题]                    │ ← 这里填充你的文案
│                                      │
│                              ~~~~~   │ ← 右下角水印
└──────────────────────────────────────┘
```

**可变内容**:
- `[内容A]` `[内容B]`: 你的对比照片
- `[引导思考的问题]`: 例如"同样的场景,为什么一个有故事,一个没有?"

**示例主题**:
- 打卡照 vs 有故事的照片
- 正面光 vs 侧面光
- 记录 vs 表达

## 品牌一致性要点

### 什么是固定的(品牌识别)
1. 水波纹+鱼的视觉符号
2. 蓝灰色+暖米色的色调
3. "水鱼故事构图"的品牌名
4. 品牌标语(3选1)
5. 留白充足的排版风格

### 什么是可变的(内容表达)
1. 照片内容(日常物品、人文场景、构图案例等)
2. 文案内容(对比分析、方法论、引导问题等)
3. 分析角度(构图、光线、情绪、故事等)
4. 系列主题(日常观察、记录vs表达、构图诠释等)

---

## 总结

**核心原则**:
> 框架统一,内容多样
> 一眼认出是"水鱼故事构图",但每次都有新的思考

**使用流程**:
1. 确定内容主题
2. 选择对应模板(对比型/解读型/引导型)
3. 填充可变内容(照片+文案)
4. 检查品牌元素(标识+色调+标语)
5. 发布

这样,无论你发布什么内容,都能保持品牌的一致性和识别度! 🎨
