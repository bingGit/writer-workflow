# 写作思路 - 《为什么你的目标让你越来越累》(v2)

## 参考风格融合

本文采用 `.gemini/参考文章风格/风格.md` 的写作规范：

| 风格要素 | 落地方式 |
|---------|---------|
| 短句为主 | 每句话控制在15字以内，节奏紧凑 |
| 段落极短 | 一两句话就换段，形成呼吸感 |
| 叙事感强 | 开篇用"有一天"引入场景 |
| 具体场景 | "刷第47个AI工具教程"、"咖啡凉了" |
| 比喻生动 | "身体投票"、"目标是过滤器" |
| 冷静克制 | 不用感叹号，不煽情 |

## 独特性融合

| 维度 | 文中体现 |
|------|---------|
| 科班的诅咒 | "我一个科班出身的人，竟然还没有非科班做出来的东西好" |
| 肉身智慧 | "让我真正停下来的，不是什么顿悟，而是累" |
| 无私的爱 | "我不想让曾经的自己白白痛苦" |

## 结构

```
场景切入 → 模仿欲望（三角形）→ 恐惧生成器 → 身体先知道 → 真正目标 → To Be转换
```

## 与v1版本的区别

- **句式**：v1较长，v2极短
- **段落**：v1使用空行分隔，v2一两句换段
- **情绪**：v1温暖陪伴，v2冷静克制
- **结构标记**：v1无分隔线，v2无分隔线（保持一致）
