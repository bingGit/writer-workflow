## 封面图设计

### 使用模板:思考引导型

**设计方案**:
```
┌──────────────────────────────────────┐
│  ~~~~~ 🐟 水鱼故事构图              │
│                                      │
│    [一把椅子/咖啡杯的照片]           │
│                                      │
│  摄影老师私藏的3个"看"的练习          │
│  让你的照片秒变高级                  │
│                                      │
│  练习1:换个角度看东西                │
│  练习2:拍两张对比看                  │
│  练习3:慢慢看细节                    │
│                                      │
│  不打卡拍照,只思考表达                │
│                                      │
│                              ~~~~~   │
└──────────────────────────────────────┘
```

**配图要求**:
- 照片:一个日常物品(椅子/咖啡杯/绿植)
- 光线:侧光,有阴影和质感
- 色调:蓝灰色背景(#E8EEF2)
- 文字:思源宋体,清晰易读

## 正文配图设计

### 图1:练习1 - 换个角度看东西

**使用模板**:故事解读型

**设计方案**:
```
┌──────────────────────────────────────┐
│  ~~~~~ 🐟 水鱼故事构图              │
│                                      │
│         [一把椅子的照片]              │
│                                      │
│  练习1:换个角度看东西(10分钟)         │
│                                      │
│  不要想"这是椅子"                    │
│  只看:                               │
│                                      │
│  ① 光线怎么照 ──→ [箭头标注]        │
│  ② 有哪些线条 ──→ [箭头标注]        │
│  ③ 阴影的形状 ──→ [箭头标注]        │
│                                      │
│  忘掉"这是什么",专注看"长什么样"     │
│                                      │
│                              ~~~~~   │
└──────────────────────────────────────┘
```

**配图要求**:
- 主体:一把简单的椅子
- 角度:侧面45度,能看到光影
- 标注:用箭头指向光线、线条、阴影的位置
- 色调:暖米色背景(#F5F1E8)

## 品牌一致性检查

### 每张图必须包含:
- [x] 右上角:`~~~~~ 🐟 水鱼故事构图`
- [x] 右下角:`~~~~~` 水波纹水印
- [x] 品牌色调:蓝灰色或暖米色
- [x] 留白:至少25%
- [x] 字体:思源宋体(标题) + 思源黑体(正文)

### 调性要求:
- [x] 有故事感,不只是技术展示
- [x] 引导思考,不只是告诉答案
- [x] 人文关怀,温暖的调性
- [x] 日常可复制,不炫技

## 拍摄建议

### 拍摄对象选择:
- **练习1**:椅子、杯子、书本(简单、常见)
- **练习2**:咖啡杯、绿植、窗边物品(阴影明显)
- **练习3**:名作或你的优秀作品(层次丰富)

### 拍摄要求:
- 光线:自然光,侧光为主
- 背景:简洁,米白色或浅灰色墙面
- 角度:45度侧面,能看到光影
- 质感:强调阴影和立体感

### 后期处理:
- 色调:统一调整为蓝灰色或暖米色
- 对比度:适当提高,强化阴影
- 饱和度:降低,保持克制感
- 锐化:适度,保持自然

## 文字标注规范

### 字体:
- 标题:思源宋体 Bold (48px)
- 副标题:思源黑体 Medium (32px)
- 正文:思源黑体 Regular (24px)

### 颜色:
- 主标题:#2A3A4A (深蓝灰)
- 正文:#4A5A6A
- 弱化文字:#8A9AAA

### 排版:
- 左对齐
- 行距:1.5倍
- 段落间距:20px
- 标注箭头:45度角

## 使用流程

1. **准备素材**:
   - 拍摄3个练习的示范照片
   - 准备1张名作或优秀作品
   - 准备1张你的代表作品

2. **套用模板**:
   - 封面图:思考引导型
   - 正文图1:故事解读型
   - 正文图2:故事对比型
   - 正文图3:思考引导型
   - 结尾图:思考引导型

3. **添加品牌元素**:
   - 右上角:品牌标识
   - 右下角:水波纹水印
   - 底部:品牌标语

4. **检查一致性**:
   - 色调统一
   - 留白充足
   - 字体规范
   - 调性温暖

5. **导出发布**:
   - 格式:PNG
   - 尺寸:1080×1350(小红书竖图)
   - 分辨率:72dpi

## 总结

这套配图方案:
- ✅ 符合"水鱼故事构图"品牌框架
- ✅ 保持视觉一致性(色调、标识、排版)
