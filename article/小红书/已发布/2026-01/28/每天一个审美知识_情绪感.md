# 每天一个审美知识｜设计的"情绪感"是什么？

"同样一个页面，
有人让你想待着，有人让你想关掉。"

📷 你是否也有过这种感觉？

打开一个网站，还没看清文字，
你就已经觉得"这个很高级"或者"这个很吵"。

这不是玄学，
而是设计中最隐秘的力量——
**情绪感 (Emotional Design)**。

🎬 什么是情绪感？

如果布局和功能是设计的"骨架"，
那么情绪感，就是设计的"灵魂"。

它决定了用户看到页面第一秒时的判断：
专业可靠？温暖亲切？还是先锋前卫？

🔍 情绪从哪里来？

其实，你的大脑在你还没读完文字之前，
已经通过这些元素做出了判断：

▫️ **颜色**
莫兰迪色 = 宁静、高级
高饱和对比色 = 活力、紧迫
暗黑色调 = 神秘、专注

▫️ **形状**
圆角 = 安全、温和
锐角直线 = 力量、严谨
有机曲线 = 治愈、艺术感

▫️ **留白**
拥挤的页面让人焦虑，
充满负空间的页面让人冷静。

💡 试着用"情绪组合"去设计

把设计元素当作调料，根据目标情绪进行组合：

1️⃣ **宁静、治愈**
莫兰迪色 + 巨大负空间 + 极细文字
→ 像置身于清晨的艺术馆

2️⃣ **安全、专业**
雾霾蓝 + 毛玻璃层级 + 严谨栅格
→ 像置身于现代化的私人银行

3️⃣ **亲和、温暖**
燕麦色 + 柔和大圆角 + 淡金色点缀
→ 像午后的咖啡馆

4️⃣ **科技、先锋**
暗黑色调 + 霓虹色点缀 + 强对比线条
→ 像赛博朋克的未来空间

🌌

好的设计，
不是让用户"看懂"了什么，
而是让用户"感受到"了什么。

下次做设计之前，
先问自己一个问题：

"我想让用户进来第一秒，
感觉自己身处什么样的空间？"

答案里，藏着你的设计方向。
